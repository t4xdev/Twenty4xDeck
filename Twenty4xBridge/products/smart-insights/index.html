How it works

How Smart Insights works

Run and schedule a report

  1. Choose the report and set date range, entity, vessel and module filters.
  2. Run it, then open the records behind any number.
  3. Save it with a name and choose who can see it.
  4. Add a schedule with cadence and recipients.

Built-in controls

Controls and compliance

  • Results always respect each user’s company and vessel scope.
  • Saving or sharing a report never grants extra access.
  • Every export states its generation time, filters and scope.
